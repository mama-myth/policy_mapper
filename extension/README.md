# Policy-to-Code Mapper VS Code Extension

## Overview
This Visual Studio Code extension provides point-of-action security and policy guidance for developers working on Python source code.

## Commands
- `Policy-to-Code: Analyze Current File` (`policyToCode.analyzeFile`): Analyzes the active Python file using the local Policy-to-Code Mapper backend and displays non-blocking diagnostic warnings and hovers.
- `Policy-to-Code: View Traceability` (`policyToCode.viewTraceability`): Displays the transparent chain: Source Code -> Observed Pattern -> Internal Policy -> Regulatory Context -> Action.
